# 009 — 모의투자는 사이트 자체 가상계좌 + KIS 실시간 시세(조회만) (2026-11-26)

## 결정
💹 모의투자 탭은 **증권사 모의계좌로 주문을 보내지 않고**, 이 서버(`paper.py`)가 실제 호가·체결을 보고 체결을 계산하는 가상계좌로 만든다.
KIS(한국투자증권) 키는 **시세 조회에만** 쓴다(`kis.py`에 주문 함수 없음).

## 이유
- 사용자 요청: 정규장 + 시간외 거래, 시작 금액 직접 지정, 회차별 결과, 원할 때 리셋.
- KIS 모의계좌는 시작 금액·리셋·회차 기록을 API로 다룰 수 없고, 모의투자 주문 시간도 공식 문서로 확인되지 않음.
- 실제 주문 가능한 키를 주문에 쓰지 않으니 더 안전하다. KIS 모의계좌는 로드맵 F1(자동매매 주문 시험)에 남겨 둔다.

## 체결 규칙 (실제 시장 근사)
| 세션 | 시간 | 체결 |
|---|---|---|
| 넥스트레이드 프리 | 08:00~08:50 | NXT 호가로 연속 체결 |
| 장전 시간외 | 08:30~08:40 | 전일 종가로 바로 |
| 시가 동시호가 | 08:40~09:00 | 모았다가 9시 시가로 (지정가 조건 맞으면) |
| 정규장 | 09:00~15:20 | 통합(KRX+NXT) 호가로 연속 체결 |
| 종가 동시호가 | 15:20~15:30 | 모았다가 종가로 |
| 넥스트레이드 애프터 | 15:30~20:00 | NXT 호가로 연속 체결 |
| 장후 시간외 | 15:40~16:00 | 오늘 종가로 바로 |
| 시간외 단일가 | 16:00~18:00 | 실제 단일가 체결이 나올 때 그 가격 (종가 ±10% 안 지정가만) |

- 시장가: 반대쪽 호가 잔량을 차례로 먹음(모자라면 마지막 호가로). 지정가: 반대쪽 최우선 호가가 닿으면 체결, 실제 체결가가 정확히 내 가격이면 그 체결 수량만큼(줄 서기 근사), 더 유리한 가격에 체결이 나면 남은 수량 전부.
- 내 주문이 호가를 바꾸지 않는다고 본다(소액 기준). 큰 주문은 실제보다 유리하게 체결될 수 있음.
- 세션이 끝나면 남은 수량은 자동 취소(당일 주문). 휴장일은 KIS 휴장일 조회로 거른다.
- 수수료 0.015%(매수·매도), 매도 세금 0.20% — `paper.FEE_RATE`·`TAX_RATE`.
- 호가 단위·상하한가 검사, 미체결 매수는 주문 가능 금액에서, 미체결 매도는 매도 가능 수량에서 뺀다.

## 모의투자 모드 · 통합 주문 (11-26 오후, 사용자 요청)
- "탭을 옮겨 다니지 말고, 증권사 앱처럼 시간대가 이어지면서 그냥 거래" → 💹 탭에서 주문하던 방식을 바꿈.
- 위쪽 **[💹 모의투자 ON/OFF]** 스위치(localStorage `PPM`). 켜면 국내 종목 차트 옆에 호가·주문·이 종목 보유/대기 주문이 붙고,
  **차트를 누르면 그 가격(호가 단위로 맞춤)이 주문 가격**에 들어간다. 차트에 평균 단가(노랑)·대기 주문(매수 빨강·매도 파랑 점선) 선.
  휴대폰은 아래 [매수][매도] 막대 → 주문창이 아래에서 올라옴. 끄면 차트 탭은 예전과 같다. 💹 탭은 내 계좌(회차·리셋·보유·미체결·체결).
- 주문은 세션을 고르지 않는 **통합 주문**(`session="auto"`): 그때그때 시각·종목(NXT 거래 여부)으로 세션을 고른다 (`paper.auto_session`).

| 시각 | NXT 거래 종목 | 그 밖 종목 |
|---|---|---|
| 08:00~08:50 | NXT 프리 연속 체결 | (08:30~08:40) 시장가만 전일 종가, 지정가는 시가 동시호가 대기 |
| 08:50~09:00 | 시가 동시호가 | 시가 동시호가 (08:40~) |
| 09:00~15:20 | 정규장(통합 호가) | 같음 |
| 15:20~15:30 | 종가 동시호가 | 같음 |
| 15:30~20:00 | NXT 애프터 연속 체결 | 15:40~16:00 시장가만 오늘 종가, 16:00~18:00 단일가(지정가만) |

- 미체결 지정가는 **그날 장이 끝날 때까지 이어진다**: 9시 전 주문은 시가 동시호가, 15:30 전 주문은 종가 동시호가에도 참여하고, 그 뒤 다음 시간대로.
  NXT 종목은 20:00, 그 밖은 18:05(단일가 마지막 반영 여유)에 취소. 장이 없는 시간엔 "언제부터" 안내와 함께 받지 않는다(예약 주문 없음).
- 예전처럼 세션을 정해 보낸 주문(API `session=regular` 등)도 그대로 동작(기존 기록 호환).

## 시세
- 보는 종목 하나만 실시간: `STOCKVIEW_KIS_WS=1` 서버는 KIS 웹소켓(통합·NXT·시간외 호가/체결), 아니면 1.5초마다 조회.
  웹소켓은 키 하나에 연결 하나라 한 서버(집 서버)만 켠다. 11-26 시험에서 구독은 동시에 3개까지(신규 계좌 제한으로 보임).
- 다른 종목의 미체결은 10초마다 현재가로 확인.

## 기록
- `data/paper.sqlite`(git 제외): rounds(회차)·positions·orders·fills·equity(평가 기록 — 최대 낙폭 계산).
- 회차 결과: 기간, 시작·최종 금액, 수익률, 체결 수, 승률(이익으로 끝난 매도 주문 비율), 최대 낙폭, 수수료+세금.

## 바꿀 조건
- 실제 체결과 차이가 크다고 보이면(특히 큰 주문·얇은 호가) 내 주문이 호가를 소모하는 모델로 바꾼다.
- 자동매매(로드맵 E·F)는 이 가상계좌를 먼저 쓴다. 실전 주문은 F 단계 사용자 승인 후 별도 모듈로.
