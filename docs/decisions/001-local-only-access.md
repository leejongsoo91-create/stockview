# 001. 로컬 전용 실행 — 외부 접속·클라우드 배포 보류

- 상태: **확정** (2026-08-24 결정, 2026-11-01 재확인)
- 관련 커밋: cbea323(구축) → de20423(되돌림) → e9e0745(host 규칙)

## 결정
StockView는 **본인 PC에서 혼자 쓰는 개인 도구**로 운영한다.
- 서버는 `127.0.0.1`에만 바인딩. `0.0.0.0`은 `RENDER` 환경변수가 있을 때만 (`app.py` 끝부분 `_host`)
- 실행 방식: 터미널 창을 계속 띄워두는 방식 (NSSM 서비스·작업 스케줄러는 설정 부담으로 보류)
- 핸드폰 접속(Tailscale)·클라우드/VPS 공개 배포는 하지 않음

## 지켜야 할 것
- **배포 관련 수정 시 host를 무조건 0.0.0.0으로 바꾸지 않는다** (사용자가 보안상 중요하다고 명시)
- "외부 접속" 이야기가 다시 나오면 이 결정부터 상기한다

## 다시 켤 때 참고 (트러블슈팅 교훈)
