# 007. 뉴스 제목 한글 번역 — Microsoft 무료판 주 + Google Cloud 예비 (2026-11-22)

## 상황
- 뉴스 약 580건 중 영어 제목이 절반 이상. 사용자 요청: 제목을 한글로.
- 하루 새 영어 제목 약 500건 × 평균 72자 → **월 약 110만 자** (한 번 번역한 제목은 다시 보내지 않는 기준).
- 키 없는 Google 번역 비공식 주소는 11-22 시험에서 8건 연속 요청에 모두 429 → 믿고 쓸 수 없음.

## 비교한 안
| 안 | 무료 한도(월) | 판단 |
|---|---|---|
| Microsoft Translator F0 | 200만 자 | 우리 사용량이 무료 안에 들어감. 한도를 넘으면 요금 대신 거절 |
| Google Cloud Translation | 50만 자 | 단독이면 넘침 → 유료 가능. 음성 브리핑 계정이 이미 있음 |
| DeepL Free | 50만 자 | 넘침 |
| 키 없는 Google 주소 | — | 429로 막힘 |
| LibreTranslate 직접 설치 | 무제한 | 집 서버 메모리 2~4GB, 품질 낮음 |

## 결정
**① Microsoft F0(주) → ② Google Cloud(①이 고장·상한일 때만) → ③ 원문 표시.** 두 무료 한도를 합쳐 월 250만 자.

요금 방지 두 겹:
1. 서버가 서비스별 이번 달 보낸 글자 수를 `data/news_translations.json`에 세서 **Microsoft 190만 자·Google 45만 자**에서 다음 달까지 멈춤.
2. Google 콘솔에서 하루 글자 한도(1.5만 자)·예산 알림(1,000원)을 사용자가 설정.

그 밖:
- 제목만 번역(요약까지 하면 글자 수 약 3배). 한글이 없는 라틴 글자 제목만 보냄.
- 실패하면 키·권한 오류(401·403)는 6시간, 그 밖(429·5xx)은 15분 뒤 다시 시도. 그동안 다음 서비스로.
- 키 파일: `api/azure-translator.txt`(1줄 키, 2줄 지역), Google은 기존 `api/google-tts-key.json`. 저장소 공개라 키는 `api/`에만.
- 키 받는 법: `docs/guides/azure-translator-key.md` (터미널: `scripts/news_translate_status.py --guide`).

## 바꿀 조건
- 사용량이 월 190만 자에 자주 닿으면: 번역 대상 출처 줄이기 또는 유료 전환 검토(사용자 확인 필수).
- Microsoft F0 정책이 바뀌어 요금이 생기면 즉시 키 파일을 빼서 끈다(원문 표시로 자동 전환).
